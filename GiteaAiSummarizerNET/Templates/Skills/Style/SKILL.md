---
name: style-guard
description: Ensures code changes adhere to best practices, coding standards, and maintainability rules.
---

Use this skill to assess code quality and maintainability.
1. Check for consistency with the existing codebase style.
2. Identify overly complex code (high cyclomatic complexity) and suggest simplifications.
3. Check for naming conventions and documentation completeness.
4. Highlight lines that might be difficult for other developers to understand.
