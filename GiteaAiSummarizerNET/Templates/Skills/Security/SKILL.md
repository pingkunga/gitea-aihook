---
name: security-checker
description: Analyzes code changes for security vulnerabilities, secret leaks, and insecure patterns.
---

Use this skill to inspect diffs specifically for security concerns.
1. Look for hardcoded credentials, API keys, or secrets.
2. Identify insecure encryption, hashing, or authentication patterns.
3. Check for common vulnerabilities like SQL injection, XSS, or improper access control.
4. Report any security risks clearly with recommendations for mitigation.
